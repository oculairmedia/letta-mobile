# Rive features worth using for Astra

Design handoff; sources checked 2026-09-14. Repository baseline: `2e11692c21ddcc971e2acb1609c33794ed892118`. This file proposes adoption conditions; it does not claim that the new pupil or scripts have run in either host.

| Priority | Feature | Decision and acceptance condition |
| --- | --- | --- |
| Take now | Clipping | Clip the single pupil to a socket **shape**; keep the eye assembly inside the plate. Validate combined gaze, saccade, facing, blink and pupil deformation. Clamp travel before clipping so expression remains readable. Winding matters. [Rive clipping](https://rive.app/docs/editor/manipulating-shapes/clipping). |
| Take now | Reduced motion | Complete the agreed `reduceMotion` contract with `qg77k`. The host detects the preference and supplies the Boolean; the rig authors the response. Remove decorative travel, spin, boil and Wander while preserving meaningful state feedback. Rive does **not** automatically infer which movement to suppress. [Reduced Motion](https://rive.app/docs/editor/accessibility/reduced-motion). |
| Conditional | Path Effect script | Appropriate for a living pupil **stroke**. Let `advance(seconds)` accumulate local phase; call `context:markNeedsUpdate()` so a static source path also refreshes inside a nested component. Bound amplitude and suspend advancement when inactive. Adopt only after the same exported file passes Android and desktop playback; otherwise use the supplied phase SVGs as keyed path targets, with matching point order. [Path Effect Scripts](https://rive.app/docs/scripting/protocols/path-effect-scripts). |
| Conditional | Bones and path weighting | Keep the body vector. Bones can weight its vertices and Bézier handles; image Mesh deforms raster pixels. Retain the eight-cubic body identities. Add weighted controls only if existing vertex animation cannot produce the required localized stretch, and apply deformation coherently to body paint layers. Keep plate and eye rigid. [Bones](https://rive.app/docs/editor/manipulating-shapes/bones), [Meshes](https://rive.app/docs/editor/manipulating-shapes/meshes). |
| Conditional | Nested joysticks | Use a second control for pupil parallax only with separate property ownership from existing facing. Joystick timelines scrub poses; overlapping keyed properties conflict. Confirm diagonal extremes before increasing travel. [Joysticks](https://rive.app/docs/editor/manipulating-shapes/joysticks). |
| Useful plumbing | Formula converters | Use for remapping phase and weights. A formula consumes `{Input}` or VM references; do not assume an intrinsic `time` variable or an autonomous clock. Supply a timeline-driven local phase through a Property Group, or use Path Effect elapsed time. Both avoid per-frame host updates. [Converters](https://rive.app/docs/editor/data-binding/converters), [Property Groups](https://rive.app/docs/editor/data-binding/property-groups). |
| Optional | Trim Path | A loading ring can animate stroke start/end/offset. Trim does not animate a filled dot. Retain the 22 dp dot unless a ring passes the size proof; specify any loading-glyph change explicitly. [Trim Path](https://rive.app/docs/editor/manipulating-shapes/trim-path). |
| Paint pass | Vector feather | Suitable for the soft body edge. Feathered fills require Rive's clockwise fill rule; runtime rendering requires the Rive Renderer. Scope approval to actual renderer and build results. Editor authoring is valid; this brief makes no blanket claim that CLI/RML cannot represent feather. [Fill and Stroke](https://rive.app/docs/editor/fundamentals/fill-and-stroke), [RML reference](https://rive.app/docs/runtimes/advanced-topic/rml). |
| Defer | Constraints and staging scripts | Distance constraints bound object positions, not arbitrary skin tearing. Parent a catchlight to the pupil if it only needs to follow. Suppress Wander during flashes with existing conditions first; add scripts only when native comparisons cannot express the gate. Transition conditions stay side-effect free; listener actions perform updates. [Distance](https://rive.app/docs/editor/constraints/distance-constraint), [Conditions](https://rive.app/docs/scripting/protocols/transition-condition-scripts), [Listener Actions](https://rive.app/docs/scripting/protocols/listener-action-scripts). |

## Compatibility evidence

| Surface | Known from this repository | Still to prove |
| --- | --- | --- |
| Android | `android-compose/gradle/libs.versions.toml` pins `app.rive:rive-android:11.12.0`; the avatar module uses `libs.rive.android`. Its surface uses the Compose worker/file API. This exceeds the official broad scripting floor, Android 11.1.0. | Exported Path Effect behavior, nested invalidation, reduced-motion response and combined bounds on the actual app. A general scripting floor does not prove every later protocol on every earlier SDK. |
| Native desktop | `native/desktop/README.md` records a D3D11 Rive Renderer spike verified with runtime commit `02bea09bc68eb923498a3fe77da257a96e48d2e9`; feathered rendering is documented. `build.ps1` accepts an external checkout, so this is a recorded verification revision, not an enforced dependency pin. | Script support in the actual bridge binary. The checked-in flags list text/layout, with no explicit scripting flag or Luau library. This alone does not prove exclusion. README leaves Android/runtime version alignment open. |

The [official support matrix source](https://github.com/rive-app/rive-docs/blob/main/snippets/feature-support.jsx) lists Android feathering at 10.0.0+ with the required renderer, excludes scripting from Web Canvas Lite, and marks Android semantics “Coming soon.” Use Compose accessibility labels now. Runtime event communication is deprecated; events inside a Rive file remain supported. Continue VM communication. [Runtime Events](https://rive.app/docs/editor/events/general-events).
